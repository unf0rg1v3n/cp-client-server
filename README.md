# Защищенный чат с протоколом SKID3

## Описание

Приложение с графическим интерфейсом, реализующее криптопротокол **SKID3** (Symmetric Key-based IDentification 3-pass) для взаимной аутентификации и безопасного обмена сообщениями.

### Особенности

- ✅ **Протокол SKID3** для взаимной аутентификации
- ✅ **HMAC-SHA256** в качестве однонаправленной хэш-функции, зависящей от ключа
- ✅ **AES-256-CBC** для шифрования сообщений после установления сессии
- ✅ Графический интерфейс на базе Tkinter
- ✅ Асинхронная обработка сетевых соединений
- ✅ Поддержка множества клиентов одновременно

## Криптопротокол SKID3

### Описание протокола

SKID3 — это протокол взаимной аутентификации на основе симметричного ключа, использующий три прохода (3-pass).

### Этапы протокола

Предположим, что клиент (Alice) и сервер (Bob) имеют общий секретный ключ **K_AB**.

```
1. Alice → Bob: R_A
   Alice генерирует случайное число R_A и отправляет Bob

2. Bob → Alice: R_B, HMAC(K_AB, R_A || R_B)
   Bob генерирует R_B, вычисляет HMAC и отправляет Alice

3. Alice → Bob: HMAC(K_AB, R_B || R_A)
   Alice проверяет HMAC от Bob, вычисляет свой HMAC и отправляет Bob

4. Bob проверяет HMAC от Alice
   Если все проверки прошли успешно, обе стороны аутентифицированы
```

### Генерация сессионного ключа

После успешной аутентификации обе стороны вычисляют сессионный ключ:

```
Session_Key = HMAC(K_AB, R_A || R_B || "session")
```

Этот ключ используется для шифрования всех последующих сообщений с помощью AES-256-CBC.

### Криптографические примитивы

1. **HMAC-SHA256** — для:
   - Взаимной аутентификации сторон
   - Генерации сессионного ключа

2. **AES-256-CBC** — для:
   - Шифрования сообщений чата после установления сессии

3. **Случайные числа** — для:
   - Генерации nonce (R_A, R_B)
   - Генерации IV для AES

## Запуск

### 1. Запуск сервера

```bash
python server.py
```

Сервер запустится на `127.0.0.1:8888` и будет ожидать подключения клиентов.

### 2. Запуск клиента(ов)

В отдельном терминале (или терминалах для нескольких клиентов):

```bash
python client.py
```

Откроется графический интерфейс чата.

## Безопасность

### ⚠️ ВАЖНО

Данная реализация создана в **образовательных целях**. Для использования в продакшене необходимо:

1. **Безопасное хранение общего секретного ключа**
   - В текущей реализации ключ хардкоден в коде
   - Для реального использования применяйте защищенное хранилище ключей

2. **Управление ключами**
   - Реализуйте безопасный обмен ключами (например, через Diffie-Hellman)
   - Регулярная ротация ключей

3. **Защита от атак повтора (replay attacks)**
   - Добавьте временные метки и проверку свежести nonce

4. **Дополнительная защита**
   - Добавьте таймауты для аутентификации
   - Ограничение количества попыток аутентификации
   - Логирование и мониторинг

## Как это работает

### Процесс подключения клиента

1. **Установка TCP соединения**
   - Клиент подключается к серверу

2. **Аутентификация по протоколу SKID3**
   - Обмен случайными числами (R_A, R_B)
   - Взаимная проверка HMAC
   - Установление сессионного ключа

3. **Обмен сообщениями**
   - Все сообщения шифруются AES-256-CBC
   - Каждое сообщение имеет уникальный IV

### Формат сообщений

**Аутентификация:**
```json
// Шаг 1: R_A от клиента
{"ra": "<base64-encoded R_A>"}

// Шаг 2: R_B и HMAC от сервера
{"rb": "<base64-encoded R_B>", "hmac": "<base64-encoded HMAC>"}

// Шаг 3: HMAC от клиента
{"hmac": "<base64-encoded HMAC>"}

// Подтверждение
{"status": "authenticated", "client_id": <id>}
```

**Сообщения чата:**
```json
{"encrypted": "<base64-encoded IV+ciphertext>"}
```

## Преимущества протокола SKID3

1. **Взаимная аутентификация** — обе стороны убеждаются в подлинности друг друга
2. **Защита от атак MITM** — использование HMAC предотвращает подмену сообщений
3. **Forward Secrecy** — каждая сессия имеет уникальный ключ
4. **Эффективность** — только 3 прохода для аутентификации
5. **Простота** — основан на симметричной криптографии

## Технические детали

### Размеры ключей и параметров

- **Общий секретный ключ (K_AB)**: 256 бит (32 байта)
- **Случайные числа (R_A, R_B)**: 256 бит (32 байта)
- **HMAC**: SHA-256 (256 бит / 32 байта)
- **AES**: 256 бит ключ, 128 бит IV
- **Размер блока AES**: 16 байт

### Производительность

- Аутентификация: ~3-5 мс
- Шифрование сообщения: ~1-2 мс
- Дешифрование сообщения: ~1-2 мс
